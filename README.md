# Vinod Loganathan Ramesh Kumar — professional portfolio

Recruiter-focused static portfolio for Staff/Principal platform engineering and AI infrastructure roles. Authored HTML and CSS live in `dist/`; no build step or JavaScript is required.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist` and visit `http://127.0.0.1:4173`.

## Editing

- `dist/index.html`: profile, experience, metrics, selected work, contact links, and metadata.
- `dist/styles.css`: base styles, hero, metrics, navigation, and responsive layout.
- `dist/details.css`: work, career, credentials, and contact sections.
- `.openai/hosting.json`: existing Sites identity and static output configuration. Reuse this identity for subsequent publishing.

The output is portable static HTML/CSS and can be served by any static web host. The current Sites review publication is private. Public recruiter sharing requires an explicitly chosen public hosting/audience setting.
